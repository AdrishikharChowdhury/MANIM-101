# Lecture 07: Basic Intro

Creating professional intro scenes with reusable functions and tech stack display.

## Features
- Helper functions for fade and write operations
- Dynamic SVG color handling
- Grouped text and image components
- SurroundingRectangle for text boxes
- Background blur effects

## Assets
- assets/background.jpg - Background image
- assets/mongodb.svg - MongoDB logo
- assets/nextjs.svg - Next.js logo
- assets/typescript.svg - TypeScript logo

## Usage
```bash
manim main.py BasicIntro -p
```
