# Lecture 06: Logos

Displaying SVG logos with background effects. Showcases technology stack visualization.

## Features
- SVG rendering with SVGMobject
- Multiple logo arrangement
- Background blur effects
- Grouped text and image objects

## Assets
- assets/background.webp - Background image
- assets/mongodb.svg - MongoDB logo
- assets/nextjs.svg - Next.js logo
- assets/typescript.svg - TypeScript logo

## Usage
```bash
manim main.py Logos -p
```
