# RRS Outro

Manim outro card for the **Round-Robin Scheduling Simulation** project.

## Scene

- `RRS_Outro` — animated "Thank You For Watching!" card.
- Uses `assets/background.jpg` (blurred with Pillow).

## Render

```bash
bash run/run.sh RRS_Outro
```

Or directly:

```bash
uv run manim -pqh src/rrs_outro/__init__.py RRS_Outro
```

The rendered video is written to `media/videos/__init__/1080p60/RRS_Outro.mp4`.
